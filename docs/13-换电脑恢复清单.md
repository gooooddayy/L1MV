## 2. 三步恢复

### ① 下载

- 整仓 ZIP：<https://github.com/gooooddayy/L1MV/archive/refs/heads/main.zip>
- 只要产物：<https://github.com/gooooddayy/L1MV/releases/latest/download/L1MV-v1.0.0.html>

> `git clone` 在部分网络下会握手失败。失败就直接下 ZIP，别耗。

### ② 解压 → 双击

`播放器视频生成器.html` 就是全部运行时。**不需要 npm install、不需要起服务器。**
把它单独拷到空文件夹里也能跑（已实测：空目录 + 单文件，1920×1080 正常渲染）。

### ③ 想改代码 / 跑测试

```bash
# 1) 改 bench/run.mjs 顶部的 EDGE 路径（默认是 Windows 的 Edge）
# 2) 冒烟
node bench/run.mjs "C:/…/L1MV/播放器视频生成器.html?debug=1" bench/probes/probe-sanity.js window
# 3) 三种导出（要 1–2 分钟）
node bench/run.mjs "C:/…/L1MV/播放器视频生成器.html?debug=1" bench/probes/probe-final.js window
```

`?debug=1` 才会挂 `window.__app`（探针依赖它）。正常打开时没有这个全局。

## 5. 仓库里没有的三样东西

| 缺什么 | 影响 | 怎么办 |
|---|---|---|
| **字体子集源文件**（5 个 woff2 + chars.txt，4.78 MB） | 想加字/换字体时要重新子集 | ① **能从 HTML 里还原**（下面脚本）；② 或按 [docs/11](11-字体与许可.md) 从上游重新子集 |
| **逐日开发日志**（96 KB 原始记录） | 想看最细的当天记录 | 内容已蒸馏进 `docs/00–14`、CHANGELOG、时间线；原始 log 未上传 |
| **旧版本快照**（v59/v60 两份 html） | 想回退到上一版 | 用 GitHub 的 commit 历史（每次改动一个 commit）或 Release |

### 从 HTML 还原字体（不需要联网）

```python
import re, base64, os
s = open('播放器视频生成器.html', encoding='utf-8').read()
os.makedirs('fonts-restored', exist_ok=True)
for fam, b64 in re.findall(r'data-family="([^"]+)"[^>]*>([A-Za-z0-9+/=]+)</script>', s):
    raw = base64.b64decode(b64)
    assert raw[:4] == b'wOF2', fam          # woff2 魔数，校验没截断
    name = fam.replace('L1MV ', '').lower() + '.woff2'
    open('fonts-restored/' + name, 'wb').write(raw)
    print(name, len(raw))
```

还原出来的就是 4.78 MB 那 5 个文件里对应的子集（Noto 726,168 / 楷 885,136 / 毛笔 1,717,940 / 行书 1,234,052 / 圆体 448,888 字节）。
要**加字**的话还得从上游拿全量字体，再按 [docs/11](11-字体与许可.md) 的子集命令重跑一遍。

## 6. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| `git clone` 卡住/握手失败 | 网络 | 下 ZIP |
| 不能 `git push` | 同上 | 网页 Upload files，或走 Git Data API（[docs/12](12-发布与维护.md)） |
| 双击打开是空白 | 扩展名被改成 `.txt` / 浏览器太旧 | 确认 `.html`，换 Chrome/Edge |
| 字体全变成黑体 | 编辑器把 `#fontStore` 那段 base64 改坏了 | 用 `git diff` 看是否动到 `<script type="text/plain"` 段；重下文件 |
| Pages 打开很慢 | github.io 在部分网络下只有几十 KB/s | 直接下 Release |
| 探针报 `__seedDemo is not defined` | 没通过 `run.mjs` 跑（它负责注入 seed.js） | 用 run.mjs，别直接粘探针 |
