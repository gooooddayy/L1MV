# 09 · 同类工具调研

> 调研时间：2026-10-31。星数与价格会变，结论看的是「形态」而不是数字。

## 1. 结论先放前面

这个品类**没有强势的开源项目**。GitHub 上叫得出名字的同类仓库，星数大多在 5–150 之间，且几乎全是「Python + ffmpeg 脚本」或「在线服务的前端壳」。商业侧则被在线 SaaS 占据，共同点是**上传 → 云端渲染 → 下载**。

于是留下一个很明确的位置：

> **单文件、离线、真 MP4、中文歌词排版、免费无水印、素材不出本机。**

这六件事同时做到的，目前没有第二个。

**观察**：
- 高星的都是**库**（mp4-muxer）或**别的形态**（扩展、卡片），真正做「歌词播放器视频生成器」的都很小。
- 唯一形态接近的 ScrollSong，卡在「MP4 要后端」这一步——这恰好是 L1MV 用 WebCodecs + 自写封装解决掉的核心问题。
- 没有项目强调「离线」「素材不出本机」「内置中文字体」。

## 5. 差异化定位（一句话版本）

> **给别人做「在线生成器」，给 L1MV 做「可以拷进 U 盘带走的生成器」。**

三条支撑：

1. **隐私**：未发布母带不上传。这是 SaaS 结构上做不到的。
2. **零成本启动**：不用注册、不用装、不用配环境。双击一个 6.6 MB 的文件。
3. **中文优先**：内置 5 款可商用中文字体，LRC 的四种时间戳与五种编码都吃。海外工具在这块普遍是空白。

## 6. 关键词空白（做 SEO 的机会）

| 关键词 | 现状 | 机会 |
|---|---|---|
| `歌词播放器视频生成` | 无对应工具，只有教程与 SaaS 广告 | **强**：几乎没有竞品占位 |
| `音乐播放器效果生成` | 零散 | **强** |
| `LRC 转视频` / `lrc to mp4` | 只有脚本类项目 | 中 |
| `歌词滚动视频 制作 免费` | 被剪辑软件教程占据 | 中：需要内容型页面 |
| `黑胶唱片 视频 生成` | 有 SaaS，无开源 | 中 |
| `lyric video generator offline` | 搜索结果多为在线工具 | **强**：意图明确、竞争低 |
| `single file html video generator` | 极少的极客向内容 | 中：适合 HN / Reddit |
| `WebCodecs MP4 封装` | 中文资料稀缺 | 中：技术博客引流 |

## 7. 威胁与应对

| 威胁 | 影响 | 应对 |
|---|---|---|
| SaaS 的 SEO 预算远大于个人项目 | 搜索前排被占 | 打长尾 + 社区内容（教程、对比、实测数据） |
| GitHub Pages 在国内访问不稳 | 中文用户体验差 | 同时提供 Release 直链；文档里写清「下载后本地打开」 |
| 大厂剪辑软件内置同类模板 | 需求被吸收 | 强调离线/隐私/批量一致性；做「一条命令出 5 条竖版」的批量场景 |
| 被当成「盗版歌词工具」 | 合规风险 | README 明确：不提供、不内置、不分发任何音乐或歌词；示例用公有领域文本 |
