# 01 · 产品说明

## 1. 它解决什么问题

发一首歌，除了音频，还需要一条能发出去的视频：YouTube 的歌词版 MV、抖音/Reels/Shorts 的竖版、朋友圈的 15 秒预告。

现有做法各有各的麻烦：

- **剪映 / PR**：能做出一样的效果，但每次发歌都要重做一遍：对时间轴、调字体、加倒影、导关键帧。一条 4 分钟的歌，熟练也要半小时。
- **在线 SaaS**（VEED、Capify、EchoWave 等）：上传音频 → 云端渲染 → 下载，带水印或按次收费，而且**要把未发布的母带传到别人服务器**。
- **开源脚本**（Python + ffmpeg）：要配环境，中文歌词排版基本靠系统字体，换个电脑就废。

L1MV 的目标只有一个：**把「给一首歌配一条播放器风格的视频」压缩成拖三个文件、点一次导出。**

## 2. 给谁用

| 用户 | 典型场景 |
|---|---|
| 独立音乐人 / 卧室制作人 | 新歌上线，需要一条歌词版 MV 和有音轨的竖版切片 |
| 翻唱 / 二创作者 | 每次都要出同款视觉，模板化最快 |
| 短视频运营 | 一条歌拆 5 条竖版，要求风格统一、无水印 |
| 播客 / 电台 / 有声书 | 长音频配封面 + 章节名滚动 |
| 不想上传素材的人 | 未发布母带、客户素材，不能出本机 |

## 3. 输入输出契约

### 输入（都可不给，缺了有兜底）

| 素材 | 支持格式 | 缺了会怎样 |
|---|---|---|
| 封面 | JPG / PNG / WebP / GIF / BMP / AVIF / SVG；>2400px 自动降采样 | 用主色渐变底（从歌词/默认色取），不中断 |
| 音频 | MP3 / M4A / AAC / WAV / FLAC / OGG / Opus / WebM | 无声片，照常导出，状态栏注明 |
| 歌词 | LRC / TXT（UTF-8/UTF-16/GB2312/GBK/Big5） | 纯音乐版，只显示歌名与封面 |

**明确拒绝**：HEIC（浏览器解不了，导入即提示转 JPG）、WMA / APE / AIFF（Chrome 解码器不支持，导入即报错，不拖到导出才炸）。

### 输出

| 维度 | 选项 |
|---|---|
| 容器 | MP4（默认，H.264 + AAC）/ MOV（无 AAC 编码器时，H.264 + PCM） |
| 分辨率 | 720P / 1080P（默认）/ 2K 2560×1440；手机端隐藏 2K |
| 画幅 | 横版 1920×1080 / 竖版 1080×1920（分辨率按短边换算） |
| 帧率 | 快速编码固定 30；兼容录制为实时 VFR |
| 体积 | 1080P 约 8–11 Mbps（0.12 bpp），10 秒片约 1.5–3 MB |

## 4. 界面结构

### 电脑（≥1024px）

```
┌──────────────────────────────────────────────────────────┐
│ L1MV · 音乐播放器效果生成   [MP4▾][1080P▾][快速▾][导出视频]│  ← sticky，单行
├───────────────────────────────┬──────────────────────────┤
│                               │  素材（封面 / 音频）      │
│      舞台（预览画布）          │  版式（横/竖）            │
│      + 播放条 + 时间          │  参数（歌名/歌手/RPM/字号）│
│                               │  字体 / 歌词颜色          │
├───────────────────────────────┤  特效（逐项开关 + 强度）   │
│      歌词表（时间 + 文本）     │  叠加素材                 │
└───────────────────────────────┴──────────────────────────┘
```

### 手机（<700px）

底栏两个页签：**预览** / **样式**，左右跟手翻页（模拟系统桌面翻页，不是淡入淡出）。歌词表放在播放条下面，仍然可以点行编辑、拖入文件。

顶栏只留四个控件，全部是自绘下拉（`MP4 / 1080P / 快速 / 导出视频`），避免手机弹系统抽屉。

## 5. 设计原则（改功能时别违背）

1. **不打断**：导出中改参数不影响正在导出的任务（点导出那一刻做快照）；导出中面板锁定但界面不冻结。
2. **所见即所得**：导出画面与预览逐像素一致。预览和导出共用 `renderAt()`，唯一区别是画布尺寸按比例缩放（K）。
3. **失败也说人话**：每条降级路径都要说明「为什么」和「怎么办」，不许沉默降级。例如「本机没有 AAC 编码器，已改 MOV（H.264 + 未压缩 PCM），剪映可导入」。
4. **不随便中止**：缺封面、缺歌词、缺音频、编码器失败，都换一条路继续；只有用户点取消或内存到顶才停。
5. **参数只在需要时出现**：导出清单（封面/歌词行数/音频时长/特效数）只在导出过程中显示，结束即消失。
6. **按钮可重复使用**：不做「点一次就禁用」的交互，导出可以连点（内部用任务号收敛）。

## 6. 功能边界（不做什么）

| 不做 | 理由 |
|---|---|
| 4K | 浏览器编码器扛不住，收益低（见 ADR-02） |
| MKV 容器 | 浏览器不能编码，剪映也不是首选 |
| WebM 作为主格式 | 剪映不认；只在没有 H.264 时保底并补时长索引 |
| 音频编辑（裁剪/降噪/变调） | 有专门工具；这里只做「把音频完整放进画面」 |
| 云端存储 / 账号 / 分享链接 | 一联网就失去「素材不出本机」这个核心卖点 |
| AI 生成歌词或封面 | 会引入模型、体积、审核；且与「离线单文件」冲突 |
| 歌词自动打轴 | 需要 ASR 模型；用户手上通常已经有 LRC |

## 7. 术语表

| 词 | 含义 |
|---|---|
| **舞台 / 场景** | `buildScene(K)` 产出的离屏画布与布局参数集合，导出时是快照 |
| **封面卡** | 画面左侧带圆角与投影的方形封面，可选「唱片弹出」动效 |
| **歌词行** | LRC 的一行（可含多个时间戳）；当前行高亮，上下行淡出 |
| **K** | 分辨率缩放系数，`K = 目标高 / 1080`；布局按 K 重建而不是整体缩放位图 |
| **快速编码** | WebCodecs 路径，逐帧渲染 + 编码，比实时快 |
| **兼容录制** | MediaRecorder 路径，实时抓帧，兼容性最好 |
| **PCM 兜底** | 没有 AAC 编码器时把未压缩音频写进 MOV |
