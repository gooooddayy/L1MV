一句话看懂：把同一张图分别做成「压暗的背景」「清晰的封面卡」「圆形的 CD」，让 CD 藏在卡片下面，用一段位移关键帧把它向右抽出，再补一段旋转关键帧让它匀速转——剩下的倒影、摇晃、雨滴、泡泡变焦，全部是给这个结构加"氛围"的配料。

04

分步制作：9 步落到参数

每步都给了具体数值。原教程说"调整合适的大小"的地方，这里换成了可直接输入的占比。

01

建工程 + 背景压暗

约 2 分钟 · 决定整体影调
新建项目›主轨道›不透明度
  • 画布 1920×1080，30fps；素材 放大到 130% 以上铺满，避免边缘露黑
  • 不透明度拉到 60；后面若发灰，加调节：对比度 +10、饱和度 +8
  • 可选：加"模糊" 15–25，让背景彻底退到后景
别做：背景别用另一张图。同一素材压暗才有"同一场景"的连贯感。
02

做封面卡（1:1 + 圆角）

约 3 分钟 · 视觉主体
复制›切画中画›编辑›裁剪 1:1›蒙版
  • 裁剪比例选 1:1，缩放高度到画面 44%（1080 下约 475px）
  • 蒙版 → 矩形 → 宽高调成一致（= 正方形），圆角 20，羽化 0–1
  • 位置：水平中心约 x 18.5%，垂直中心 y 48%
易错：剪映的"圆角"是 0–100 的相对值，不是像素。20 ≈ 短边的 10%，475px 的卡片就是 24px 圆角。
03

做投影（黑影）

约 2 分钟 · 立体感来源
导入黑底›裁剪 1:1›层级 置底›矩形蒙版
  • 黑底素材同样裁 1:1，蒙版尺寸与封面卡完全一致，圆角同样 20
  • 羽化 5–8，不透明度 40–50，相对卡片右下偏移 6–8px
  • 要"发光"而不是"投影"：换白底素材，羽化拉到 20
层级：黑影必须置底，否则会盖住 CD 的滑出路径。
04

做圆形 CD 并弹出

约 5 分钟 · 全场核心
复制封面卡›蒙版 圆形›层级 全部轨道›关键帧
  • 复制封面卡这一层，蒙版换成圆形，直径 = 卡片边长 × 0.91
  • 层级面板 → 全部轨道 → CD 拖到封面卡之下、贴纸之下（此时它被卡完全盖住）
  • 在 0.9s 打位置关键帧（X = 卡片中心）；1.7s 打第二帧，X 右移 = CD 直径的 72%
  • 第二帧缓动改成缓出，或自定义贝塞尔 0.16, 1, 0.30, 1
判断标准：成片里应当露出约 2/3 的圆面，剩下 1/3 仍被卡片压住——这是"抽出来"和"贴上去"的区别。
05

贴纸同步 + 置底

约 2 分钟 · 让圆盘像唱片
贴纸›调大小›对齐 CD 中心›同帧关键帧
  • 圆形贴纸尺寸 = CD 直径（略小 1–2% 更好），移动到 CD 正中心
  • 在 CD 的同两个时间点打关键帧，位移量完全相同
  • 层级：贴纸在 CD 之上、封面卡之下
关键：贴纸和 CD 必须"同帧同距离"，差一帧就会出现圆环和盘面分离的诡异抖动。
06

统一时长 + CD 旋转

约 4 分钟 · 让画面"活"起来
拉长所有轨道›时间轴末尾›基础属性 旋转
  • 先把所有轨道拉到与歌词同长（否则旋转只转到一半就断了）
  • CD 轨道末尾 → 基础属性 → 旋转输入角度，自动生成末尾关键帧
  • 所有旋转关键帧缓动 = 线性，否则会出现"转一下停一下"
不要：别给贴纸也加旋转关键帧。正圆转了看不出，但贴纸上的中心孔一旦不对称就会露馅。
07

歌词轨 + 抠像

约 4 分钟 · 信息层
导入歌词›编辑 裁剪›抠像 色度抠图
  • 导入 LRC 或"识别歌词"，裁剪掉多余边距，缩放到右侧 46%–96% 区域
  • 如果是绿幕歌词素材：抠像 → 色度抠图，吸绿色，强度 45–60、阴影 10
  • 如果是 LRC 生成的文本：不需要抠像，直接设字号 40、行距 1.9、白色 + 当前行发光
注意：LRC 导入的是文本层，对它做色度抠图会整层消失——这一步要看你导入的到底是文本还是绿幕视频。
08

播放器三特效

约 2 分钟 · 播放器识别度
特效›画面特效›播放器三›参数
  • 纹理 = 0：去掉颗粒/噪点，UI 变干净
  • 旋转 0°（横屏）；若特效默认竖排，用 -90°
  • 作用对象 = 全局；把进度条组件贴到卡片下方约 4% 画面高处
层级：UI 要在歌词之上、氛围特效之下，否则倒影会把进度条也倒一遍。
09

氛围四件套 + 音效

约 5 分钟 · 决定"质感"
水中倒影›左右摇晃›雨滴晕开›泡泡变焦
  • 水中倒影：垂直位置 0.78 画面高，水波 35，透明度 30，模糊 25
  • 左右摇晃：幅度 1.5、速度 0.4（再大就成晕船）
  • 雨滴晕开：数量 4、大小 70、速度 0.5
  • 泡泡变焦：放片头，缩短到 0.3–0.5s，缩放 0.85 → 1.0
  • 音效：弹出终点帧对齐 whoosh 峰值（提前 2 帧起更自然）
原则：四个特效全部"只调一档"。氛围特效调狠了，画面会糊成一团，反而更廉价。

节奏换算：让旋转跟着拍子走

大多数人随便填个 720°，所以看着"不对劲"。唱片转一圈 = 一拍，才是最舒服的。

一拍时长0.833s
一拍帧数25.0帧
总圈数18.0圈
旋转角度6480°
关键帧建议每 2 圈打一帧，共 9 组，全部线性

拟真派可以改用黑胶实际转速：33⅓ rpm = 0.556 转/秒，45 rpm = 0.75 转/秒；15 秒分别约 8.3 圈与 11.3 圈。

常见翻车点

照着做还是不对，九成是下面这几条。

CD 是从封面卡前面弹出来的
层级反了。打开「层级 → 全部轨道」，把 CD 拖到封面卡下面。判断方法：静止时 CD 应该完全不可见。
弹出过程一顿一顿的
关键帧缓动是"线性"或中间有多余关键帧。精简成 2 帧，末帧改缓出；如果仍卡，检查是否开了"智能补帧"却只有 24fps 素材。
圆环和盘面在弹出时错位
贴纸的关键帧比 CD 晚了一两帧。把两者的关键帧框选后整体对齐到同一时间点，位移值复制粘贴，别手动拖。
旋转到一半就停了
轨道没拉长，或旋转末尾关键帧落点早于素材结尾。先把所有轨道拉齐到歌词长度，再打旋转末帧。
旋转速度忽快忽慢
单帧角度过大时剪映会自动走"最短路径"。改成每 2 圈一个关键帧并全部线性，能彻底消除跳变。
歌词抠不干净，边上带绿边
色度抠图强度不够或素材压缩产生绿边。强度提到 55–65、阴影 10；仍不行就换「混合模式 → 滤色」直接把黑底去掉。
整幅画面发灰、没精神
背景压到 60% 后必然掉对比。回主轨道加调节：对比度 +10、饱和度 +8、亮度 −5；或叠一层深蓝渐变、混合模式"正片叠底" 15%。
倒影把 UI 也倒了一遍
特效作用对象是"全局"且 UI 层在特效之下。把播放器 UI 轨道移到特效之后（轨道更靠上），或把倒影改成只作用于指定轨道。
导出后明显变卡 / 掉帧
水中倒影 + 雨滴 + 摇晃三层叠加很吃性能。导出前把预览分辨率降到 1/2，或把雨滴特效预渲染成一段素材再叠。
竖屏版怎么改
画布换 1080×1920，卡片缩到高 26%、上移到 y 30%，歌词改为底部横排两行，CD 仍从卡片右侧抽出；其余特效参数不变。
