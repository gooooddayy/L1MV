# 11 · 字体与许可

## 1. 为什么内置字体

中文歌词的观感 90% 取决于字体。系统字体的现实是：

| 平台 | 有的 | 没有的 |
|---|---|---|
| Windows | 宋体、黑体、楷体、仿宋、微软雅黑 | 任何有设计感的手写/圆体 |
| macOS | 苹方、宋体-简、楷体-简 | 毛笔、行书 |
| Android | 思源黑体（部分机型只有 Regular） | 宋、楷、手写 |
| iOS | 苹方 | 宋、楷、手写 |

也就是说：**不内置，90% 的用户只能得到一种黑体歌词。**

## 2. 选型与体积

子集口径：GB2312 一级字 3755 + ASCII + 中文标点 + 全角 + 常用符号 = **4191 字**。

| 字体 | 上游 | 字重 | 子集后 woff2 |
|---|---|---|---|
| 宋体 `L1MV Song` | Noto Serif SC | 700 | 0.69 MB |
| 楷体 `L1MV Kai` | 霞鹜文楷 LXGW WenKai | 700 | 0.84 MB |
| 毛笔 `L1MV Brush` | 马善政 Ma Shan Zheng | 400 | 1.64 MB |
| 行书 `L1MV Script` | 志莽行书 Zhi Mang Xing | 400 | 1.18 MB |
| 圆润 `L1MV Round` | 站酷快乐体 ZCOOL KuaiLe | 400 | 0.43 MB |
| | | **合计** | **4.78 MB** |

base64 后膨胀约 1.37 倍 → **6.5 MB**，占 HTML 的 96%。

### 为什么选这 5 款

覆盖「正式/温和/有力/洒脱/活泼」五种气质，且都是 OFL（可商用、可嵌入、可修改）。没有选更漂亮的商业字体，是因为授权不允许随代码分发。

## 3. 子集化命令

```bash
# 1) 生成字符集
python - <<'PY'
chars = []
# GB2312 一级汉字（3755）
for hi in range(0xB0, 0xD8):
    for lo in range(0xA1, 0xFF):
        try: chars.append(bytes([hi, lo]).decode('gb2312'))
        except: pass
chars += [chr(c) for c in range(0x20, 0x7F)]          # ASCII
chars += list('，。、；：？！“”‘’（）《》〈〉【】…—·～')
chars += [chr(c) for c in range(0xFF01, 0xFF5F)]      # 全角
chars += list('￥℃№→←↑↓★☆○●◎△▲□■◇◆')
open('chars.txt','w',encoding='utf-8').write(''.join(dict.fromkeys(chars)))
PY

# 2) 子集化
python -m fontTools.subset 源字体.ttf \
  --text-file=chars.txt \
  --flavor=woff2 \
  --no-hinting \
  --desubroutinize \
  --layout-features='*' \
  --output-file=L1MV-xxx.woff2
```

`--desubroutinize` 与 `--no-hinting` 是为了减小体积；中文不需要 hinting。

## 4. 内嵌方式

```html
<script type="text/plain" class="l1font"
        data-family="L1MV Song" data-weight="700">d09GMgAB…</script>
```

**不是** `<style>` 里的 `@font-face`。原因：CSS 解析器会对每个 base64 token 做词法分析 + 字符串驻留，6.4 MB 让 HTML 解析从 40 ms 涨到 590 ms。`text/plain` 的 script 只被当作纯文本扫过（找 `</script>`），代价接近 0。

加载：

```js
async function ensureFontLoaded(id){
  const node = document.querySelector(`.l1font[data-family="${id}"]`);
  if(!node || node.dataset.done) return;
  const face = new FontFace(id, `url(data:font/woff2;base64,${node.textContent})`,
                            { weight: node.dataset.weight });
  await face.load();
  document.fonts.add(face);
  node.dataset.done = '1';
  node.textContent = '';        // 注册完立刻释放，省 1–2 MB 常驻
}
```

三个必须遵守的点：

1. **默认字体是系统 sans**，所以首屏一个字体都不解码。
2. **切字体必须 await**：`ensureFontLoaded → clearTextCache → buildLayout → renderAt`，否则当帧还是旧字形。
3. **导出前必须 await**：否则整片按回落字体栅格化，而且看不出来（字形差别小的时候）。

## 5. 生僻字与回落

子集只有 4191 字，超出范围的会按字体栈回落系统字体：

```
"L1MV Brush", "Songti SC", "SimSun", serif
```

实测：龘靐齉爩𠮷 不会崩，只是字形不统一。这是明确的取舍——要把 CJK 全字符集塞进来，单款字体就要 8–10 MB。

## 6. 授权与合规

5 款字体均为 **SIL Open Font License 1.1**：

- 允许商用、嵌入、修改、再分发；
- 修改后的版本**不得使用原保留名称**——所以内部家族名统一改成 `L1MV *`；
- 必须随分发附带授权全文 → 见 [fonts/LICENSE-OFL.txt](../fonts/LICENSE-OFL.txt)；
- 不得单独售卖字体本身 → 本项目只随 HTML 整体分发。

详细声明见 [NOTICE.md](../NOTICE.md)。

## 7. 换字体 / 加字体

1. 准备 ttf/otf，按上面的命令子集化。
2. base64：

```bash
base64 -w0 L1MV-xxx.woff2 > xxx.b64
```

3. 在 `#fontStore` 里追加一个 `<script type="text/plain" class="l1font" data-family="L1MV Xxx" data-weight="400">…</script>`。
4. 在字体列表里注册显示名（`buildFontOptions`）。
5. 重新跑 `probe-embedded2`，确认新字体与其他字体两两签名不同（证明真的生效）。

> 加一款字体大约 +1 MB。加之前想清楚：**它解决的是「有没有」，还是「好不好看」**。前者值得，后者通常是个人偏好。
